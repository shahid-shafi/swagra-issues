# Privacy Policy

**Last updated:** June 23, 2026

Swagra ("the Extension") is a Chrome extension that allows developers to import, explore, and test OpenAPI and Swagger API specifications directly in the browser.

## Data Collection

Swagra does **not** collect, store, transmit, sell, or share any personal information.

Swagra does not collect:

* Personally identifiable information
* Authentication credentials
* Financial or payment information
* Health information
* Location information
* Browsing history
* User activity
* Personal communications

## API Requests

When a user sends an API request using Swagra, the request is sent directly from the user's browser to the API endpoint selected by the user.

Swagra does not proxy, inspect, store, or transmit API requests or responses to any servers owned or operated by Swagra.

## Local Storage

Swagra may store the following information locally on the user's device using Chrome Storage APIs:

* Imported OpenAPI or Swagger specifications
* User preferences and settings
* Recently opened specifications

This information remains on the user's device and is not transmitted to external servers.

## Third-Party Services

Swagra does not use advertising services.

Swagra does not sell or transfer user data to third parties.

## Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. Any changes will be reflected in this document.

## Contact

For support, bug reports, or feature requests, please open an issue on the GitHub repository.
